# Changelog

## 3.3.3

### Fixed

- Restored native sidebar sizing for the iPhone Duo half-open layout.
- Fixed Stats cards being forced into narrow columns near the fold.

## 3.3.2

### Fixed

- Fixed file uploads not starting after selecting files in the iOS Files tab.

## 3.3.1

### Fixed

- Fixed Photos freezing when opened from the iOS terminal accessory bar or Chat Mode.
- Kept chat drafts and restored keyboard input after closing Photos.

## 3.3.0

### Changed

- Improved iPhone Duo navigation and layouts, with a wider sidebar and Stats cards arranged on each side of the fold.
- Updated iOS sheets with native dismiss and confirmation controls.
- Simplified workspace selection and server environment filters on iOS.
- Grouped iOS file actions in the More menu.
- Centered the view selector in the horizontal iOS toolbar.
- Improved SSH key setup buttons and shortened session actions to show the session tool name.
- Images upload automatically when pasted by default. Existing image paste settings are preserved.
- Updated iOS terminal scrolling to use native scrolling.

### Fixed

- Adjusted connection notices to fit and center within the available content area.
- Removed duplicate safe-area spacing from floating terminal controls on iOS.
- Improved Eternal Terminal recovery after backgrounding and restoration of existing sessions.
- Fixed iOS hardware keyboard attachment and terminal pane focus.
- Restored iOS keyboard input after closing attachment pickers.
- Fixed fast attachment uploads in Normal Mode after closing iOS pickers.
- Kept the iOS microphone accessory stable when switching tabs.
- Fixed iOS server navigation bars and keyboard background layout.
